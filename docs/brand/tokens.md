# Basique Industrie

One mark, one color. Every product can add a second accent later; this gold is the shared start.

| Token | Hex | Use |
| --- | --- | --- |
| `basique.ink` | `#0B0B0B` | Ground, avatars, dark chrome |
| `basique.gold` | `#E8B328` | Primary. Buttons, marks, focus |
| `basique.gold.bright` | `#F3C44A` | Lit facets, hover |
| `basique.gold.deep` | `#B88914` | Folded facets, pressed |
| `basique.paper` | `#F4F1EA` | Light surfaces |

The mark is `mark.svg`: a capital B built from flat plates, the same way Zed builds its Z. Keep the circular-safe padding. Do not add a ring, wordmark, or second hue to the avatar.
